## 欢迎

这是我的个人网站，使用 **Astro** 构建，托管在 **Vercel** 上。

## 技术栈

- **框架**: Astro - 专为内容网站设计的静态站点生成器
- **样式**: Tailwind CSS - 实用优先的 CSS 框架
- **内容管理**: Decap CMS - 基于 Git 的在线编辑器
- **评论**: Giscus - 基于 GitHub Discussions 的评论系统
- **搜索**: Pagefind - 静态站点搜索方案

## 为什么选择 Astro？

Astro 的核心优势是 **默认零 JavaScript**。这意味着除非你明确需要交互，否则页面不会加载任何 JS，因此加载速度极快，SEO 友好。
